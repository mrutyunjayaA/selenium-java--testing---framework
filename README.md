# Selenium Automation Framework

## Website Tested
Parabank Banking Application

## Technologies Used
- Java
- Selenium WebDriver
- TestNG
- Maven

## Features
- Login Testing
- Registration Testing
- Fund Transfer Testing
- Screenshot on Failure
- Reusable Methods
- Reporting

## Project Structure
```text
src/test/java
src/main/java
testng.xml
pom.xml
```

## How to Run
1. Open project in Eclipse
2. Update Maven dependencies
3. Run testng.xml
